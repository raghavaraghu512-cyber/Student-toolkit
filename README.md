# 🎓 Student Toolkit

A professional online calculator platform designed for students.

Student Toolkit provides free and easy-to-use academic tools like CGPA Calculator, Attendance Calculator, Percentage Calculator, Age Calculator, Unit Converter, and Scientific Calculator.

---

## 🚀 Features

### 📚 Student Calculators

✅ CGPA Calculator  
- Calculate semester and overall CGPA  
- Supports multiple subjects and credits  

✅ Attendance Calculator  
- Calculate current attendance percentage  
- Find required classes to reach target attendance  

✅ Percentage Calculator  
- Calculate exam and academic percentages  

✅ Age Calculator  
- Find exact age in years, months, days, hours and minutes  

✅ Unit Converter  
- Length conversion  
- Weight conversion  
- Temperature conversion  

✅ Scientific Calculator  
- Basic arithmetic operations  
- Trigonometry functions  
- Logarithms  
- Mathematical constants
